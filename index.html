아직 서명·기기 검증이 남아 있는 초기 버전이므로, 아래 설치 안내를 먼저 확인해 주세요.

macOS

Apple Silicon (M1 이상)
macOS 14 이상

Mac용 다운로드 DMG · 2.4 MB

임시 서명 · Apple 공증 전

Mac 설치 방법
  1. DMG를 열고 Puff를 응용 프로그램 폴더로 옮겨요.
  2. Puff를 실행해요. 보안 경고로 열리지 않으면 시스템 설정 → 개인정보 보호 및 보안에서 앱 이름과 출처를 확인하고 ‘그래도 열기’를 선택해요.

Intel Mac용 빌드는 아직 제공하지 않아요.

Windows

Windows 10 22H2 / Windows 11
64비트 (x64)

Windows용 다운로드 ZIP · 66 MB

코드 서명 전 · Windows 실기기 검증 전

Windows 설치 방법
  1. ZIP 전체를 원하는 폴더에 압축 해제해요.
  2. 폴더 안의 Puff.exe를 실행해요. 함께 들어 있는 설정 파일은 그대로 두세요.
  3. 작업 표시줄의 숨겨진 아이콘(∧)에서 퍼프 메뉴를 찾을 수 있어요.

런타임은 포함되어 있어요. 서명되지 않은 앱이라 보안 경고가 나타날 수 있어요. 받으신 파일의 출처를 확인해 주세요.

GOOD TO KNOW

궁금한 게 있나요?

Mac과 Windows끼리도 같이 쓸 수 있나요?

같은 광장과 친구 방을 사용하고, 이름·외형·상태·손 흔들기·메시지 형식을 공유해요. Windows는 첫 배포 버전이라 기기에서의 동작 확인이 남아 있고, 일부 기능과 움직임은 Mac과 달라요.

데모인가요? 실제 사람이 보이나요?

이 페이지의 배포 파일에는 실제 서버 연결 설정이 포함되어 있어요. 온라인으로 접속한 다른 사람들과 함께할 수 있어요. 서버 설정 파일이 없는 개발용 빌드에서는 가상 동료를 보여줘요.

내 화면이나 입력한 내용을 다른 사람이 볼 수 있나요?

화면 내용, 창 제목, 키보드 입력 내용은 보내지 않아요. 이름·하는 일·외형·활동 상태와 직접 보낸 인사·메시지를 공유해요. 친구 방 정보는 광장에 알리지 않고, 말하기는 현재 친구 방에서만 보여요.

방과 참가 목록은 서버에 저장해요. 앱은 접속 상태·인사·메시지를 대화 기록으로 저장하지 않아요. 프로필과 로그인 정보는 내 기기에 보관해요.

작업에 방해가 되지는 않나요?

퍼프가 없는 곳의 클릭은 원래 앱으로 전달해요. 트레이·메뉴바에서 방해 금지, 잠시 숨기기, 투명도를 설정할 수 있어요. 전체화면 앱에서는 기본적으로 숨겨져요.

두 버전의 기능이 모두 같나요?

꾸미기와 친구 방, 인사, 짧은 메시지가 공통 기능이에요. Windows에는 앱 종류에 따른 하는 일 자동 감지, 함께 일한 시간 통계·기지개 알림, 일부 움직임 효과가 아직 없어요.
